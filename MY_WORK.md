Overview
This project simulates a Round-Robin CPU Scheduler in Java using multithreading concepts. The simulation generates process parameters dynamically based on a random seed tied to my Student ID.
Key Features Implemented
Dynamic Time Quantum & Burst Times: Generated dynamically using Random(studentID) seed (445052279).
Multithreading & Ready Queue: Managed processes using Thread, LinkedList<Thread> for the ready queue, and HashMap for process tracking.
Context Switching: Counts and logs every process execution state and time quantum completion.
Performance Metrics: Calculates and prints Context Switches, Individual Waiting Times, Turnaround Times, and Average Waiting Time.
